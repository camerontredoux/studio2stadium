# Icon

The mockup's 57 Phosphor (regular) icons, drawn inline with `currentColor` so they follow the text colour.

- `size`: `sm` (14px, default) inside buttons, chips, menus and rows; `md` (16px) in nav items and strips; `lg` (20px) in the mobile dock; `xl` (32px) for a state icon; or a number.
- Decorative by default (`aria-hidden`); pass `label` when the icon alone carries meaning (a connection status).
- Need another icon? Use another Phosphor regular icon rather than mixing in another set.
- Consumer provides: `name`, optional `size`, `label`, `className`, `style`.
