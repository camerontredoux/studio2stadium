# Checkbox

A native 14px checkbox tinted `fg`, used to select table rows.

- In a table, use `hideLabel` and give each box a `label` like "Select Jane Doe"; the header box is "Select all".
- Inside a menu, use a `Menu` item with `checkbox: true` instead; it draws the same mark as a filled square.
- Consumer provides: `checked`, `onChange`, `label`.
